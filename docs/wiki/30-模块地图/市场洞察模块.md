# 市场洞察模块

## 职责

`market_insight` 在 22:15 只读正式日频事实、因子、事件和市场汇总，生成：

- 短线接力情绪分与大盘风险偏好分。
- 冰点、修复、活跃、高潮、退潮主阶段和辅助状态。
- 涨停梯队、题材上下文、龙虎榜/公告关联证据。
- 情绪模型历史校准、T+1/T+3 市场环境验证和盘后页面数据。

本模块不调用 Provider、LLM 或券商，不生成个股买卖建议。模型版本用于保存不可变参数和历史可复现结果，不代表行情/因子资产存在多套物理版本。

## 正式输入

| 输入 | 用途 |
| --- | --- |
| `t_market_summary_daily` | 市场宽度、成交/换手、资金、趋势扩散、涨跌停生态和七大指数状态。 |
| `t_stock_factor_daily` | QFQ 趋势、收益、波动、市值、换手和资金标准因子。 |
| `t_daily_bar` | BFQ 实际行情和昨日涨停溢价。 |
| `t_limit_event_daily` | 涨停、跌停、炸板、一字/换手板和连板结构。 |
| `t_sector_factor_daily/t_sector_leader_daily` | 题材热度、持续性和龙头强度。 |
| `t_market_north_flow_daily/t_margin_summary_daily` | 非阻塞市场辅助及实际披露日。 |
| `t_lhb_event/t_lhb_seat_detail/t_announcement` | 涨停关联证据，不能写成已证明因果。 |
| `t_provider_ingest_audit` | 接口完成、合法零行、延迟或失败证据。 |

市场宽度、资金、趋势扩散、波动率和七大指数环境直接读取 `t_market_summary_daily`，情绪基线不再重复扫描全市场日 K/因子。涨跌停零行仍必须结合 `t_provider_ingest_audit` 判断；22:15 涨停证据生成后，只定向补齐市场汇总的最高连板/晋级率和板块龙头排名，不重算全市场汇总。

个股北向持仓不再作为输入或页面卡片；缺少北向/两融只降低辅助信息，不阻塞核心评分。

## 双分与周期

正式结果表为 `t_market_emotion_model/t_market_emotion_daily`。股票范围统一排除 ST、北交所/BSE 和上市前 5 个实际交易日的新股。

### 短线接力情绪分

- 短线结构 40%：换手自然涨停、合格跌停、炸板率、连板晋级率、连板高度/梯队。
- 赚钱效应 25%：上涨比例、中位涨跌、宽幅涨跌比、昨日涨停溢价。
- 题材主线 20%：热点涨停密度、持续性、龙头强度。
- 资金活跃 15%：成交额相对均值、主力资金、市场级北向流。

### 大盘风险偏好分

- 市场广度 30%。
- 趋势扩散 25%。
- 流动性与资金 25%。
- 风险约束 20%。

所有指标保存绝对值、单位、方向、滚动分位、单项得分、配置/有效权重、贡献、公式、来源和新鲜度。事件或输入缺失时指标不可用，不以零代替。

主阶段优先级：数据待完成 → 冰点 → 退潮 → 高潮 → 修复 → 活跃。辅助状态独立保存试错、发酵、加速、分歧、混沌轮动或恐慌释放及数值证据。

## 模型生命周期

1. 克隆当前模型创建草稿。
2. 草稿可编辑权重、窗口、阈值和可用性规则。
3. 基线按 20 个交易日检查点分批计算，失败后可从已持久化日期续跑。
4. 校准完成后生成分数分布、阶段持续天数和 T+1/T+3 环境验证。
5. 管理员人工审阅后启用；旧模型参数归档，历史每日结果不覆盖。

发布前必须满足两张评分卡各 100%、阈值有序、基线完整。日常计算不自动调权；验证的正向、反向或混合关系只供研究判断。

T+1/T+3 验证衡量的是分数对后续市场宽度和七大核心指数环境的区分，不代表个股策略胜率。T+3 为后续三个开市日的累计结果，不是第三天单日变化。

## 涨停和题材证据

`t_market_limit_up_evidence_daily` 保存涨停股票的板数、市场快照、板块上下文及龙虎榜/公告关联。连板必须按 `t_trade_calendar` 的连续开市日计算；中间交易日未涨停即重置。

题材热度以 `t_sector_factor_daily` 为正式来源，多龙头读取 `t_sector_leader_daily`。板块行情延迟时，依赖成分股事实的部分仍可计算，但质量标记必须反映行情/资金覆盖。

## API 与页面

- `GET /api/v1/market-insights/emotion-daily`：双分、阶段、指标审计、质量、证据和趋势。
- 情绪模型列表/详情、草稿编辑、校准、验证、发布和启用接口。
- 盘后页只展示一个正式双分情绪区，不显示旧兼容情绪。
- 情绪模型页展示基线双线、阶段时间带、降级日、分组验证和样本数。

页面不触发 Provider 请求；若启用模型尚无当日结果，明确返回未计算原因，不回退到其他模型或伪造中性分。

## 数据质量

- 日 K、事件、正式因子或市场汇总未完成时，结果为 `pending/degraded` 并保存缺失证据。
- 合法零涨停/跌停必须由接口审计证明。
- 北向和两融展示最新实际披露日，不用系统当天填充。
- 情绪计算不得读取未来交易日，不得把回测后验指标混入评分输入。
- 核心事实完整时，单日情绪和报告事实目标 1 分钟内完成。
