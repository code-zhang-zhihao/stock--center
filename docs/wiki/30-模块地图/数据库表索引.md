# 数据库表索引

每日资产逐表字段、单位、生产阶段和关联关系见 [每日事实沉淀数据字典](../20-核心流程/每日事实沉淀数据字典.md)。

## 正式数据分层

| 层 | 表 | 说明 |
| --- | --- | --- |
| 接口审计 | `t_provider_ingest_audit` | 永久保存脱敏参数、请求字段、返回/入库行数、哈希、完成状态与错误；不保存响应正文。 |
| 主数据 | `t_stock`、`t_trade_calendar`、`t_sector_basic`、`t_sector_component`、`t_index_basic`、`t_index_component` | 股票、交易日、板块、指数及当前有效成分关系。 |
| 分钟事实 | `t_minute_bar` | MooTDX 分钟价格、均价、成交量和可得成交额；按交易日分区，保留 30 个交易日。 |
| 分钟因子 | `t_stock_factor_minute` | 1/5/15 分钟收益、MA、20 分钟量比、日内位置和有真实金额时的 VWAP；保留 30 日。 |
| 个股窄事实 | `t_daily_bar`、`t_stock_daily_basic`、`t_stock_adjust_factor`、`t_stock_fund_flow_daily` | BFQ 日 K、估值流动性、复权因子和各档资金流；金额/股数在入库边界归一。 |
| 个股事实视图 | `v_stock_daily_fact` | 以日 K 为主干连接 daily basic 与资金流，供普通查询。 |
| 个股正式因子 | `t_stock_factor_daily` | 唯一 QFQ 策略/回测/情绪因子宽表；`stk_factor_pro` 直接写类型列，本地补可重算因子。 |
| 事件 | `t_limit_event_daily`、`t_lhb_event`、`t_lhb_seat_detail`、`t_announcement` | 涨跌停/炸板/停牌、龙虎榜和公告证据。 |
| 板块 | `t_sector_bar`、`t_sector_fund_flow_daily`、`t_sector_factor_daily`、`t_sector_leader_daily` | 同花顺板块行情、资金、类型化因子和每日前五龙头。 |
| 指数 | `t_index_bar`、`t_index_daily_basic`、`t_index_factor_daily` | 七大核心指数行情、可得估值和类型化趋势/波动因子。 |
| 市场 | `t_market_summary_daily`、`t_market_north_flow_daily`、`t_margin_summary_daily` | 每日市场宽度/资金/趋势/事件汇总及非阻塞北向、两融辅助。 |
| 情绪与证据 | `t_market_emotion_model`、`t_market_emotion_daily`、`t_market_limit_up_evidence_daily` | 正式双分情绪、不可变模型参数审计和涨停关联证据。 |
| 因子目录 | `t_factor_definition` | 因子名称、类型列、公式、单位、窗口、来源和可重算性。 |
| 实时缓存/审计 | `t_quote_snapshot`、`t_tick_trade` | 实时底座主要使用 Redis/内存；仅策略触发等需要审计时选择性落库。 |
| 低频公司事实 | `t_financial_statement`、`t_financial_indicator`、`t_corporate_action`、股东相关表 | 财报、分红、公司行动和股东专题，不复制到本轮日频宽表。 |
| 配置 | `t_system_config`、`t_config_value`、`t_config_option`、`t_runtime_call_log` | 数据源、LLM、通知和运行参数。 |
| 调度 | `t_scheduler_job`、`t_scheduler_job_run`、`t_scheduler_tag`、`t_scheduler_job_tag` | 任务定义、运行审计、标签目录和任务标签关联。 |
| 股票池与策略 | `t_stock_pool`、`t_stock_pool_member`、`t_stock_pool_realtime_policy`、`t_strategy_*` | 股票池、实时优先级、策略版本、候选、信号、回测和模拟交易。策略版本是参数审计，不代表行情资产存在多轨。 |
| 外部标的池 | `t_market_universe`、`t_market_universe_member` | TickFlow 等 Provider 原始标的池目录和成员有效期历史。 |

## 关键表契约

### `t_stock_factor_daily`

- 唯一键：`stock_code + trade_date`；`price_basis=qfq`。
- 技术指标：78 个 `stk_factor_pro` QFQ 类型列和 4 个结构计数。
- 本地指标：收益、量额比、平均成交额、波动、高低点、回撤、相对沪深 300、横截面分位和资金累计。
- 服务字段：换手、估值、股本、市值、资金。
- 质量字段：五个数据组状态、`quality_flags`、来源、计算修订、历史天数和计算时间。
- 不保存专业 JSON、`source_map`、`missing_factors` 或物理快照。

### `t_market_summary_daily`

每交易日一行，集中保存市场覆盖、涨跌分布、成交/换手、平均 20 日波动率、资金、MA 扩散、创新高低、涨停生态、七大指数平均收益/振幅及北向/两融披露日。情绪与报告复用该表，不重复扫描全市场明细。

### `t_provider_ingest_audit`

合法零事件必须由 `status=complete_zero` 证明；表中无业务行不等于接口完成。敏感参数和响应正文禁止入库。

## 已退出运行时的表

最终清理后不再存在：旧股票因子、因子激活/验证视图、专业因子 JSON 档案、技术快照、旧单分情绪、旧板块热度、个股北向持仓、市场 `daily_info`、筹码日表、Provider Raw 正文和因子集激活表。代码、调度和页面不得引用这些对象。

## 迁移 SQL

最终收口必须按顺序执行：

```text
docs/sql/77-daily-assets-final-prepare.sql
docs/sql/78-daily-assets-final-backfill.sql
docs/sql/79-daily-assets-final-cutover.sql
部署并重启正式应用，运行个股/板块/指数有界历史因子任务
docs/sql/79b-daily-assets-final-resume.sql
观察至少 7 日并确认备份
docs/sql/80-daily-assets-final-cleanup.sql
```

`77/78` 可在线执行；`79` 需要维护窗口并保持 Scheduler worker 停止；`79b` 通过覆盖门禁才恢复原启用任务；`80` 会物理删除遗留对象，不可逆。

完整历史 SQL 索引见 [SQL 目录说明](../../sql/README.md)。
