# 数据库表索引

## 三层数据

| 层 | 表 | 说明 |
| --- | --- | --- |
| Raw | `t_provider_raw_record` | 保存外部源原始响应，防止字段丢失。 |
| Canonical | `t_stock`、`t_trade_calendar`、`t_daily_bar`、`t_minute_bar`、`t_quote_snapshot`、`t_tick_trade` | 股票基础资料和核心行情事实。 |
| Canonical | `t_sector_basic`、`t_sector_component`、`t_sector_bar`、`t_index_basic`、`t_index_component`、`t_index_bar` | 板块/概念/行业、指数和成分股事实。 |
| Canonical | `t_stock_fund_flow_daily`、`t_sector_fund_flow_daily`、`t_lhb_event`、`t_lhb_seat_detail`、`t_announcement` | 资金流、龙虎榜和公告事件事实。 |
| Reserved Canonical | `t_financial_statement`、`t_corporate_action` | 预留给财务、公司行动和后续专题数据。 |
| Derived | `t_stock_factor_daily`、`t_stock_factor_minute`、`t_technical_indicator_snapshot`、`t_factor_definition` | 保护旧库因子与技术指标，并登记新指标口径。 |
| Config | `t_system_config`、`t_config_value`、`t_config_option`、`t_runtime_call_log` | Search、LLM、Notification 的固定配置对象、Key 池和渠道/模型参数。 |
| Scheduler | `t_scheduler_job`、`t_scheduler_job_run` | 调度任务定义和运行日志；当前包含隐藏 `scheduler_noop`、板块同步和股票基础资料同步任务定义。 |
