# 行情数据查询契约
<!-- wiki-migration -->

## 核心入口

所有行情查询统一走 `MarketDataQueryService`。

| `query_mode` | 行为 |
| --- | --- |
| `db_first` | 先查数据库，缺失或过期再按 provider chain 补。 |
| `provider_first` | 先查外部源，成功后写 canonical 表。 |
| `db_only` | 只查数据库，不触发外部源。 |
| `provider_only` | 只查外部源，不写 canonical 表，但写 `t_provider_raw_record`。 |
| `refresh` | 强制刷新并 upsert canonical 表。 |

## 默认 provider 顺序

| 能力 | 默认顺序 |
| --- | --- |
| 股票基础资料 | `akshare -> mootdx` |
| 日线 | `akshare -> mootdx` |
| 分钟线 | `mootdx -> akshare` |
| quote | `mootdx -> akshare` |
| 分笔成交 | `mootdx -> akshare` |
| 板块/概念/行业 | `akshare -> mootdx` |
| 板块行情 | `akshare` |
| 指数基础/成分 | `akshare` |
| 指数行情 | `akshare -> mootdx` |
| 资金流 | `akshare` |
| 龙虎榜 | `akshare` |
| 公告 | `akshare` |
| 指标查询 | `database` |

`TushareTransport` 通过 `TushareCanonicalMapper` 已接入股票基础资料、日线、板块目录/成分、指数、个股资金流、龙虎榜与公告的既有链路。实时 quote、股票分钟线和分笔仍由 MooTDX 主导。新增 Catalog API 只代表 raw Provider 可调用；是否增加 Canonical 映射、HTTP 查询入口或 Scheduler job，必须由具体业务模块决定。

## 返回解释字段

返回 `meta` 必须包含：

- `resolved_source`
- `fallback_used`
- `attempted_engines`
- `missing_ranges`
- `staleness`
- `raw_ref`
- `persisted`
- `errors`

这些字段用于解释为什么使用某个源，以及原始响应保存在哪里。

## 过期 fallback

- `daily_bars`：库内最新 `trade_date` 早于目标日期时，尝试 provider chain；外部源失败则返回库内旧数据并写入 `missing_ranges`。
- `quote`：库内快照超过 60 秒视为过期，优先刷新；外部源失败则返回库内旧快照并写入 `missing_ranges`。

## 新增核心接口

- `GET /api/v1/market-data/query/ticks`
- `GET /api/v1/market-data/query/sectors`
- `GET /api/v1/market-data/query/sector-components`
- `GET /api/v1/market-data/query/stock-sectors`
- `GET /api/v1/market-data/query/sector-bars`
- `GET /api/v1/market-data/query/indexes`
- `GET /api/v1/market-data/query/index-components`
- `GET /api/v1/market-data/query/index-bars`
- `GET /api/v1/market-data/query/fund-flow`
- `GET /api/v1/market-data/query/lhb`
- `GET /api/v1/market-data/query/announcements`
- `GET /api/v1/market-data/query/indicators`

所有新增接口沿用同一套 `query_mode` 和 `engine_priority` 契约。`provider_only` 只写 `t_provider_raw_record`；`refresh` 强制外部刷新并 upsert canonical 表。

## 板块中心浏览契约

板块中心使用独立的只读浏览接口，不属于 `MarketDataQueryService` 的外部查询契约：

- `GET /api/v1/market-data/browse/sectors` 支持 `sector_type=concept|industry`、`provider=tushare|akshare|all`、`keyword`、`page`、`page_size`；默认只展示 Tushare 同花顺快照，默认每页 20 条。
- `GET /api/v1/market-data/browse/sectors/{sector_code}/stocks` 支持 `keyword`、`status`、`page`、`page_size`；默认每页 20 条，按板块的来源 family 查询 `t_sector_component`，再 `LEFT JOIN t_stock` 补充主数据。
- 主数据尚未同步的关联仍返回 `stock_code` 与 `metadata_json.raw.con_name`，并标记 `stock_exists=false`，不能因 `t_stock` 缺行而丢失板块成分。
- 两个浏览接口均不会调用 AkShare、Tushare、MooTDX，不落 raw，不更新 Canonical；刷新只能通过 `sync_sector_catalog` 与 `sync_stock_basic` 调度任务完成。
